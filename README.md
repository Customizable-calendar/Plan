# 📅 Customizable Calendar (가제)

> **"노트에 적듯 막 적어도, 내 맥락을 알고 일정과 할 일을 똑똑하게 정리해 주는 앱"**

사용자의 일상 패턴, 주요 인물, 반복 일정을 학습하여 자연어 메모로부터 정확한 일정과 할 일을 자동 추출·정리하는 스마트 캘린더 & To-Do 애플리케이션입니다.

앱 개발이 처음인 4명이 AI 바이브 코딩으로 공부하며 만드는 사이드 프로젝트입니다. 코드 안에서는 임시 이름 `noteApp`을 쓰고 있으며, 이름이 정해지면 함께 바꿉니다.

---

## 📌 프로젝트 개요 (Overview)

- **프로젝트 형태:** 사이드 프로젝트 (4인 개발)
- **목표:** 복잡한 입력 양식 없이 자유로운 메모만으로 신뢰도 높은 일정·할 일 생성 및 구글 캘린더 실시간 동기화
- **핵심 차별점:**
  - **문맥 기반 해석:** 단순 날짜 파싱이 아닌 사용자 맥락(근무 시간, 주변 인물, 선호 패턴)을 반영한 해석
  - **지속적 되먹임 학습:** 사용자가 수정한 내역이 '내 정보'에 누적되어 사용할수록 정확도 향상

---

## 💡 핵심 기능 및 워크플로우

1. **자유로운 메모 입력**
   - 노트에 적듯이 줄글로 편하게 작성 (예: _"민수랑 담주 화 강남 점심"_, _"금욜 보고 전에 경쟁사 자료 정리"_)
2. **신뢰 기반 확인 카드 (Confirmation Card)**
   - AI가 제안한 일정/할 일을 근거와 함께 제시 (예: _"목요일 마감으로 잡은 이유: 금 10시 주간보고"_)
   - 사용자가 검토 후 '확정' 버튼을 눌러 등록 (오등록 원천 방지)
3. **내 정보(Context) 관리**
   - 근무 시간, 점심시간, 주요 지인(가족, 동료), 고정 반복 일정을 관리하고 필요시 직접 수정/삭제
4. **구글 캘린더 연동 및 충돌 감지**
   - 실시간 연동 및 중복·충돌 일정 자동 경고

레포 뼈대에는 아래 기능의 자리도 함께 만들어 두었습니다. 포함 범위는 회의에서 확정합니다.

- 확인한 카드로 업무일지·학습일지 같은 문서 초안 만들기 (세션 템플릿)
- 저녁 수행 확인 (완료·부분·못 함·모름)

## 🛡️ 설계 및 정확도 원칙

- **몰래 등록 금지:** 모든 결과는 사용자의 확인 카드를 거치며, 무단 자동 등록을 방지합니다.
- **날짜 계산은 코드로 분리:** AI는 날짜 표현(상대 시점)만 추출하고, 절대 시점 계산은 프로그램 로직으로 수행하여 환각(Hallucination)을 방지합니다.
- **애매할 때는 단일 선택지 질문:** 불필요한 연속 질의를 최소화하고, 최대 1개의 객관식 선택지로 사용자 피로도를 낮춥니다.
- **판단 근거 명시:** 왜 해당 일시로 해석했는지 사유를 표시하여 신뢰도를 확보합니다.
- **원문 보존:** 사용자가 쓴 메모는 고치지 않고, 카드마다 원문 위치와 출처를 남깁니다.
- **AI 키는 기기에만:** 사용자 AI API 키는 기기의 보안 저장소에만 두고 서버·DB·로그로 보내지 않습니다.

## 🚀 로드맵 (Roadmap)

### Phase 1: MVP (첫 출시)

- [ ] 5분 온보딩 (기본 생활 패턴 및 주요 지인 설정)
- [ ] 자유 메모 입력 및 일정/할 일 엔티티 추출
- [ ] 해석 근거를 포함한 확인 카드 UI
- [ ] '내 정보' 조회 및 수정 화면
- [ ] Google Calendar 연동 및 일정 충돌 체크

### Phase 2: 확장 및 연동

- [ ] 음성 메모(STT) 지원 및 홈 화면 위젯
- [ ] 모바일 메신저(카카오톡 등) 공유 텍스트 붙여넣기 인식
- [ ] Slack 연동 정책 검토 및 적용 (인앱 발송 / 마켓플레이스 승인)
- [ ] 노션형 블록 에디터 고도화
- [ ] 팀 단위 미팅 일정 자동 추천 기능

주차별 마일스톤(M0~M4)과 담당별 첫 할 일은 [docs/roadmap.md](docs/roadmap.md)에 있습니다.

## 🛠️ 개발 시작하기

```bash
git clone https://github.com/Customizable-calendar/Plan.git
cd Plan
pnpm install
cp apps/mobile/.env.example apps/mobile/.env   # Supabase URL과 publishable 키 입력
pnpm dev                                        # Expo 개발 서버 실행 후 폰의 Expo Go로 QR 스캔
```

- Node 22.13 이상(또는 24)과 pnpm 10이 필요합니다. pnpm이 없으면 `corepack enable`을 먼저 실행합니다.
- 커밋 전에 `pnpm lint && pnpm typecheck && pnpm test`가 통과해야 합니다.
- 기술 스택은 Expo(React Native) + TypeScript, Supabase(로그인·DB·파일), pnpm 워크스페이스입니다. 선택 이유는 [docs/decisions/](docs/decisions/)에 있습니다.

### 📁 폴더 구조

| 폴더                 | 내용                                                                                       |
| -------------------- | ------------------------------------------------------------------------------------------ |
| `apps/mobile`        | Expo 앱. `app/`은 화면 라우트, `features/`는 기능별 코드, `lib/`는 Supabase·로그인·키 보관 |
| `packages/shared`    | 기능끼리 주고받는 타입, 예시 JSON, 세션 템플릿 JSON                                        |
| `packages/extractor` | 메모에서 일정·할 일·사람을 찾는 규칙 + AI 추출                                             |
| `packages/ai-client` | Claude·OpenAI·Gemini 호출 어댑터 (사용자 키)                                               |
| `packages/storage`   | 파일 저장소 인터페이스 (지금 Supabase, 나중에 S3)                                          |
| `packages/ui`        | 색·글꼴·공통 컴포넌트                                                                      |
| `supabase`           | DB 마이그레이션, Edge Functions                                                            |
| `docs`               | 컨벤션, 로드맵, 결정 기록, 프롬프트·학습 기록                                              |
