# 📅 Customizable Calendar (가제)
> **"노트에 적듯 막 적어도, 내 맥락을 알고 일정과 할 일을 똑똑하게 정리해 주는 앱"**

사용자의 일상 패턴, 주요 인물, 반복 일정을 학습하여 자연어 메모로부터 정확한 일정과 할 일을 자동 추출·정리하는 스마트 캘린더 & To-Do 애플리케이션입니다.

---

## 📌 프로젝트 개요 (Overview)

* **프로젝트 형태:** 사이드 프로젝트 (4인 개발)
* **목표:** 복잡한 입력 양식 없이 자유로운 메모만으로 신뢰도 높은 일정·할 일 생성 및 구글 캘린더 실시간 동기화
* **핵심 차별점:**
  * **문맥 기반 해석:** 단순 날짜 파싱이 아닌 사용자 맥락(근무 시간, 주변 인물, 선호 패턴)을 반영한 해석
  * **지속적 되먹임 학습:** 사용자가 수정한 내역이 '내 정보'에 누적되어 사용할수록 정확도 향상

---

## 💡 핵심 기능 및 워크플로우

1. **자유로운 메모 입력**
   * 노트에 적듯이 줄글로 편하게 작성 (예: *"민수랑 담주 화 강남 점심"*, *"금욜 보고 전에 경쟁사 자료 정리"*)
2. **신뢰 기반 확인 카드 (Confirmation Card)**
   * AI가 제안한 일정/할 일을 근거와 함께 제시 (예: *"목요일 마감으로 잡은 이유: 금 10시 주간보고"*)
   * 사용자가 검토 후 '확정' 버튼을 눌러 등록 (오등록 원천 방지)
3. **내 정보(Context) 관리**
   * 근무 시간, 점심시간, 주요 지인(가족, 동료), 고정 반복 일정을 관리하고 필요시 직접 수정/삭제
4. **구글 캘린더 연동 및 충돌 감지**
   * 실시간 연동 및 중복·충돌 일정 자동 경고

---

## 🛡️ 설계 및 정확도 원칙

* **몰래 등록 금지:** 모든 결과는 사용자의 확인 카드를 거치며, 무단 자동 등록을 방지합니다.
* **날짜 계산은 코드로 분리:** AI는 날짜 표현(상대 시점)만 추출하고, 절대 시점 계산은 프로그램 로직으로 수행하여 환각(Hallucination)을 방지합니다.
* **애매할 때는 단일 선택지 질문:** 불필요한 연속 질의를 최소화하고, 최대 1개의 객관식 선택지로 사용자 피로도를 낮춥니다.
* **판단 근거 명시:** 왜 해당 일시로 해석했는지 사유를 표시하여 신뢰도를 확보합니다.

## 🚀 로드맵 (Roadmap)

### Phase 1: MVP (첫 출시)
- [ ] 5분 온보딩 (기본 생활 패턴 및 주요 지인 설정)
- [ ] 자유 메모 입력 및 일정/할 일 엔티티 추출
- [ ] 해석 근거를 포함한 확인 카드 UI
- [ ] '내 정보' 조회 및 수정 화면
- [ ] Google Calendar 연동 및 일정 충돌 체크

### Phase 2: 확장 및 연동
- [ ] 음성 메모(STT) 지원 및 홈 화면 위젯
- [ ] 모바일 메신저(카카오톡 등) 공유 텍스트 붙여넣기 인식
- [ ] Slack 연동 정책 검토 및 적용 (인앱 발송 / 마켓플레이스 승인)
- [ ] 노션형 블록 에디터 고도화
- [ ] 팀 단위 미팅 일정 자동 추천 기능
