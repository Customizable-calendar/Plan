# @noteapp/extractor (담당: B)

메모 원문에서 일정·할 일·사람·아이디어 카드 후보를 찾아요.

1. **규칙 먼저**: 날짜·시간처럼 규칙으로 잡히는 건 `src/rules/`에서 바로 처리해요. 빠르고 비용이 없어요.
2. **애매한 것만 AI로**: 규칙으로 못 잡은 부분만 `options.ai`로 넘겨요.
3. **결과는 제안**: 모든 카드는 `status: 'suggested'`로 돌려주고, 확인은 사용자가 해요.

## 한국어 테스트 세트

`cases/cases.json`에 "메모 → 기대하는 카드" 예시를 모아요. "모레", "다음 주 화", "이번 주말", "3시"(오전·오후), "월말" 같은 표현을 50~100개까지 늘리는 게 M2 목표예요. 데모용 메모도 여기에 넣어요.
