# @noteapp/extractor (담당: B)

메모 원문에서 일정·할 일·사람·아이디어 카드 후보를 찾아요.

1. **규칙 먼저**: 날짜·시간처럼 규칙으로 잡히는 건 `src/rules/`에서 바로 처리해요. 빠르고 비용이 없어요.
2. **애매한 것만 AI로**: 규칙으로 못 잡은 부분만 `options.ai`로 넘겨요.
3. **결과는 제안**: 모든 카드는 `status: 'suggested'`로 돌려주고, 확인은 사용자가 해요.

## 흐름 (`src/extract.ts`)

1. `splitPieces`: 메모를 줄·문장·목록 기호로 잘라요. 위치는 원문 기준이에요.
2. 조각마다 `parseEvent`를 돌려서 이렇게 나눠요.
   - `아이디어:`로 시작하면 아이디어
   - `할 일` 접두어, `~까지`, `~해야 함`/`~하기`로 끝나거나 `오늘 할 일` 목록 아래 있으면 할 일. 날짜만 있으면 마감은 그날 23:59예요.
   - 날짜·시각이 있으면 일정. `먹었다`처럼 지난 일은 빼요.
   - `~면 좋겠다`, `~해볼까`면 아이디어
   - `민수랑`, `@지영`은 사람 (메모 안에서 한 번만)
3. 아무 카드도 안 나온 조각("회의비 2만원 정도")은 버려요. M3에 이 조각만 `options.ai`로 보내요.

캘린더 빠른 입력 같은 한 줄 입력은 `parseEvent`, `toSegments`(하이라이트)를 바로 가져다 써요.

## 아직 카드로 안 가는 것

장소, 반복, 알림은 파서가 잡지만 `Card`에 칸이 없어서 버려요. 넣으려면 `packages/shared` 타입을 바꾸는 contract PR이 필요해요.

## 한국어 테스트 세트

`cases/cases.json`에 "메모 → 기대하는 카드" 예시를 모아요. "모레", "다음 주 화", "이번 주말", "3시"(오전·오후), "월말" 같은 표현을 50~100개까지 늘리는 게 M2 목표예요. 지금 20개예요. 데모용 메모도 여기에 넣어요.
