- **화면**: 오늘 화면 섹션, `/devlog` (주별 일지·스터디 질문), `/devlog-new` (쓰기, 모달)
- **데이터**: M1은 `samples.json` + 앱이 켜져 있는 동안만. M2에 `devlogs_` 테이블로 팀원끼리 공유해요.
- **다른 기능에 주는 것**: 없음
- **받는 것**: 없음. M2에 로그인(D)의 사용자. AI 키는 지금 쓰기 화면에서 받아 `lib/secrets`에 저장하고, 설정(D)에 키 화면이 생기면 그쪽으로 옮겨요.

## 흐름

1. `/devlog-new`에서 이름을 고르면 그 사람의 이번 주 PR·이슈를 GitHub에서 불러와요(`github.ts`, 공개 레포라 키 없이). "지난주부터"로 넓힐 수 있어요.
2. 정리할 PR·이슈를 고르고, 고른 것마다 배운 점을 한두 줄 적어요. 전체 메모 칸도 있어요.
3. **AI로 일지 채우기**를 누르면 PR 본문·바뀐 파일·메모를 모아 Claude(`claude-opus-5-5`)가 공통 템플릿(`prompt.ts`의 `TEMPLATE`)을 채워요. 처음 한 번은 Claude API 키를 넣어요. 키는 폰 보안 저장소에만 있어요(docs/decisions/0002).
4. 결과를 보고 "스터디 질문 더 쉽게"처럼 말로 고쳐 달라고 하거나 직접 고쳐요. 대화가 이어져서 앞 내용을 기억해요.
5. 저장해요. 한 주에 한 사람 한 편이고, 다시 저장하면 바꿔 써요.
6. 회의 때 `/devlog`에서 주를 고르고 **스터디 질문**으로 바꾸면 질문만 먼저 보이고 답은 눌러서 열어요.

키가 없으면 **키 없이 코딩 AI에 부탁하기**로 부탁 문장을 Claude Code·Codex에 보내고 받은 답을 붙여 넣어요. **빈 템플릿으로 직접 쓰기**도 있어요.

형식(`## 만든 것`, `## 배운 개념`, `## 코드 읽는 순서`, `## 막힌 곳과 해결`, `## 스터디 질문`, `## 다음 주 할 것`)은 `prompt.ts`의 `TEMPLATE`에서 바꿔요. 스터디 질문은 `Q.`/`A.` 줄로 읽어요(`parse.ts`).
