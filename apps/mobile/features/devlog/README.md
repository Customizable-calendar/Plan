# 개발일지

- **담당**: B
- **하는 일**: 팀원이 한 주 동안 개발한 내용을 각자 코딩 AI로 정리해 올리고, 주간 회의 때 같이 보며 스터디해요.
- **화면**: 오늘 화면 섹션, `/devlog` (주별 일지·스터디 질문), `/devlog-new` (쓰기, 모달)
- **데이터**: M1은 `samples.json` + 앱이 켜져 있는 동안만. M2에 `devlogs_` 테이블로 팀원끼리 공유해요.
- **다른 기능에 주는 것**: 없음
- **받는 것**: 없음. M2에 로그인(D)의 사용자, M3에 설정(D)의 AI 키

## 흐름

1. `/devlog-new`에서 이름을 고르면 그 주 날짜가 들어간 부탁 문장(`prompt.ts`)이 나와요.
2. 문장을 복사해 각자 쓰는 코딩 AI(Claude Code, Codex 등)에 레포를 연 채로 넣어요. AI가 git 기록과 PR을 보고 정해진 형식으로 정리해요.
3. 받은 마크다운을 붙여 넣고 저장해요. 한 주에 한 사람 한 편이고, 다시 저장하면 바꿔 써요.
4. 회의 때 `/devlog`에서 주를 고르고 **스터디 질문**으로 바꾸면 질문만 먼저 보이고 답은 눌러서 열어요.

형식(`## 만든 것`, `## 배운 개념`, `## 코드 읽는 순서`, `## 막힌 곳과 해결`, `## 스터디 질문`, `## 다음 주 할 것`)은 `prompt.ts`에서 바꿔요. 스터디 질문은 `Q.`/`A.` 줄로 읽어요(`parse.ts`).
