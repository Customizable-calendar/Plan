# 카드

- **담당**: B
- **하는 일**: 메모에서 나온 카드 후보를 보여주고 확인·고치기·버리기를 받는 곳이에요. AI가 만든 카드는 사용자가 확인해야 저장돼요.
- **화면**: `카드` 탭의 `CardsScreen`, 오늘 화면의 `TodayCardsSection`
- **데이터**: `cards_` 테이블
- **다른 기능에 주는 것**: 확인된 할 일 카드를 캘린더 시간 잡기(C)와 AI 초안에 넘겨요.
- **받는 것**: `@noteapp/extractor`, 메모(A)

## 규칙

- 이 폴더 밖에서는 `index.ts`로 내보낸 것만 써요. 내부 파일 구조는 담당자가 자유롭게 바꿔요.
- 다른 기능과 주고받는 타입은 `packages/shared`에 있어요. 바꿀 때는 `contract` 라벨 PR로 올려요.
