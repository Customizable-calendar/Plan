# 수행 확인

- **담당**: C
- **하는 일**: 저녁에 오늘 할 일을 완료·부분·못 함·모름으로 체크해요. 결과는 업무일지 초안의 "한 일/못 한 일"에 들어가요. 모름은 실패로 세지 않아요.
- **화면**: `/execution` (모달)
- **데이터**: `exec_` 테이블

- 이 폴더 밖에서는 `index.ts`로 내보낸 것만 써요. 내부 파일 구조는 담당자가 자유롭게 바꿔요.
- 다른 기능과 주고받는 타입은 `packages/shared`에 있어요. 바꿀 때는 `contract` 라벨 PR로 올려요.
