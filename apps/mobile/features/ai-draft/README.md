# AI 초안

- **담당**: B
- **하는 일**: 확인한 카드만 골라 템플릿 양식으로 문서 초안을 만들어요. 원문 대신 카드를 보내서 정확하고 토큰도 적게 써요. AI는 사용자 키로 기기에서 직접 호출해요.
- **화면**: `/draft` (모달)
- **데이터**: 저장은 편집기(A)의 `docs_` 테이블로
- **다른 기능에 주는 것**: 초안 텍스트를 편집기(A)에 넘겨요.
- **받는 것**: 카드, 템플릿, `@noteapp/ai-client`, `@/lib/secrets`의 AI 키

## 규칙

- 이 폴더 밖에서는 `index.ts`로 내보낸 것만 써요. 내부 파일 구조는 담당자가 자유롭게 바꿔요.
- 다른 기능과 주고받는 타입은 `packages/shared`에 있어요. 바꿀 때는 `contract` 라벨 PR로 올려요.
