# 편집기

- **담당**: A
- **하는 일**: AI 초안이나 빈 문서를 직접 고치는 화면이에요. 처음엔 단순한 텍스트 편집으로 시작하고, 블록 편집과 `/카드` 넣기는 나중에 붙여요.
- **화면**: `/editor/[id]`
- **데이터**: `docs_` 테이블
- **다른 기능에 주는 것**: 저장한 문서를 피드(D, P1)에 넘겨요.
- **받는 것**: AI 초안 결과(B), 템플릿(sessions)

## 규칙

- 이 폴더 밖에서는 `index.ts`로 내보낸 것만 써요. 내부 파일 구조는 담당자가 자유롭게 바꿔요.
- 다른 기능과 주고받는 타입은 `packages/shared`에 있어요. 바꿀 때는 `contract` 라벨 PR로 올려요.
