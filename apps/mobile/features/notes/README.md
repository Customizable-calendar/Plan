# 막 쓰기 입력

- **담당**: A
- **하는 일**: 형식 고민 없이 메모를 막 쓰는 입력창이에요. 저장하면 B의 추출기로 카드 후보를 받아요.
- **화면**: 오늘 화면의 `QuickNoteSection`
- **데이터**: `notes_` 테이블 (원문 메모)
- **다른 기능에 주는 것**: 저장한 메모(`Note`)를 카드 추출에 넘겨요.
- **받는 것**: `@noteapp/extractor`의 `extractCards()`

## 규칙

- 이 폴더 밖에서는 `index.ts`로 내보낸 것만 써요. 내부 파일 구조는 담당자가 자유롭게 바꿔요.
- 다른 기능과 주고받는 타입은 `packages/shared`에 있어요. 바꿀 때는 `contract` 라벨 PR로 올려요.
