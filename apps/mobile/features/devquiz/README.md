# 공부 퀴즈 빌보드 (개발 기간 이벤트)

- **담당**: B
- **하는 일**: 팀원이 쓴 이번 주 개발일지로 AI가 서술형 퀴즈 5문제를 내고 채점해요. 점수로 빌보드 순위를 매겨요. 1등은 "공부하면서 개발도 열심히 한 사람", 꼴등은 "AI 딸깍하고 공부는 안 한 사람"으로 박제돼요.
- **화면**: 오늘 화면 섹션(개발 빌드에서만), `/devquiz`
- **데이터**: M1은 앱이 켜져 있는 동안만(폰마다 따로). 팀 전체 빌보드는 M2에 `devquiz_results_` 테이블이 생기면 돼요.
- **다른 기능에 주는 것**: 없음
- **받는 것**: 개발일지(devlog)의 일지·팀원·주 계산·AI 키·채팅 모양

## 규칙

- 본인 일지로만 풀어요. 이번 주 일지가 없으면 못 풀어요.
- 문제는 일지 문장을 베껴서는 못 맞히게 "왜"를 물어요(`quiz.ts`). 채점 기준은 푸는 사람에게 안 보여요.
- 문제당 20점, 100점 만점. 한 사람이 한 주에 한 번, 첫 시도만 기록해요.
- 이번 주 순위는 점수, 누적 순위는 평균 점수로 매겨요. 두 명 이상 풀어야 1등·꼴등 칭호가 붙어요(`rank.ts`).

## 출시 전에 지우기

이 기능은 개발할 때만 써요. 출시 빌드(`__DEV__`가 false)에서는 오늘 화면에 안 보이지만, 출시 전에 아래를 지워요.

1. `apps/mobile/features/devquiz/` 폴더
2. `apps/mobile/app/devquiz.tsx`
3. `apps/mobile/features/registry.ts`의 `devquiz` 두 줄 (import, 배열)
4. (M2에 만들었다면) `devquiz_results_` 테이블

개발일지(devlog)는 퀴즈를 모르기 때문에 위만 지우면 돼요. `devlog/index.ts`에서 퀴즈용으로 내보낸 것은 남아 있어도 괜찮아요.
