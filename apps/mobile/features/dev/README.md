# 개발 메뉴

- **담당**: D
- **하는 일**: 등록된 기능(`features/registry.ts`)의 탭·오늘 섹션·화면을 담당별로 모아 보여 줘요. 탭에서 바로 갈 수 없는 화면(세션·편집기·AI 초안·수행 확인)도 여기서 열어요.
- **화면**: `/dev` (오늘 탭 왼쪽 위 「개발」 버튼, 개발 중(`__DEV__`)에만 보여요)
- **데이터**: 없음

새 기능을 `scripts/new-feature.mjs`로 만들거나 `feature.screens`를 추가하면 이 메뉴에 자동으로 나와요. 여기는 고치지 않아도 돼요.
