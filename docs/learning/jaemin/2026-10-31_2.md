# Google Play·Apple App Store 등록과 Google AI Studio 무료 사용

확인일: 2026-10-31. 비용과 정책은 바뀔 수 있으므로 신청 전 연결된 공식 안내를 다시 확인한다.

## 오늘 배운 것

### 1. Google Play에 Android 앱 등록

1. **개발자 계정 만들기:** Play Console에서 개인 또는 조직 계정을 선택하고 본인·조직 확인을 진행한다. 등록비는 **미화 25달러, 최초 1회**다. [계정 등록 안내](https://support.google.com/googleplay/android-developer/answer/6112435?hl=ko)
2. **앱 만들기:** 앱 이름, 언어, 무료·유료 여부를 정한다. 앱을 구분하는 고유 이름인 패키지 이름도 준비한다.
3. **소개와 개인정보 항목 작성:** 설명, 아이콘, 화면 이미지, 연락처, 개인정보처리방침, 데이터 수집 여부와 연령 등급 등을 입력한다.
4. **앱 파일 올리기:** Android 배포 파일인 AAB를 만들고 앱 서명을 설정해 업로드한다. 서명은 배포한 앱의 제작자를 확인하는 장치다. [앱 생성·설정 안내](https://support.google.com/googleplay/android-developer/answer/9859152?hl=ko)
5. **테스트하기:** 2023-11-13 이후 생성한 개인 계정은 공개 배포 신청 전 **최소 12명이 연속 14일 이상 참여하는 비공개 테스트**가 필요하다. 조건 충족 후 공개 배포 권한을 신청하며 자동 승인되는 것은 아니다. [테스트 조건](https://support.google.com/googleplay/android-developer/answer/14151465?hl=ko)
6. **심사 요청 후 공개:** 필요한 설정을 완료하고 심사를 요청한다. 수정 요청이 오면 고쳐 다시 제출한다.

### 2. Apple App Store에 iPhone 앱 등록

1. **개발자 가입:** Apple Developer Program에 개인 또는 조직으로 가입한다. 비용은 **연간 미화 99달러 또는 현지 통화 금액**이다. 조직은 법인 확인용 D-U-N-S 번호 등이 필요하다. [가입 안내](https://developer.apple.com/programs/enroll/)
2. **앱 식별 정보 준비:** 앱의 고유 이름인 Bundle ID와 제작자를 확인할 서명 설정을 준비한다.
3. **App Store Connect에 앱 만들기:** 이름과 Bundle ID를 연결하고 설명, 화면 이미지, 개인정보 항목, 연령 등급 등을 작성한다.
4. **iOS 앱 파일 업로드:** 서명한 iOS 빌드를 올린다. 직접 빌드할 때는 보통 Mac의 Xcode를 사용하며, 별도의 클라우드 빌드 서비스를 쓸 수도 있다.
5. **테스트하기:** TestFlight로 테스트 버전을 배포해 오류를 확인한다. TestFlight 테스트는 일반 공개와 구분된다. [전체 등록 흐름](https://developer.apple.com/help/app-store-connect/get-started/app-store-connect-workflow/)
6. **심사 요청 후 공개:** 제출할 빌드를 선택하고 심사 정보를 채운다. 로그인이 필요한 앱은 심사자가 접근할 방법도 제공한다. `Add for Review` 후 `Submit for Review`까지 진행하고, 승인 후 공개한다. [심사 제출](https://developer.apple.com/help/app-store-connect/manage-submissions-to-app-review/submit-an-app/)

### 3. Google AI Studio 무료 사용량

AI Studio는 AI를 시험하는 웹 화면이고, 자동 정보 업데이트 코드에서는 **Gemini API**로 AI에 요청한다. 웹 화면 사용과 프로그램의 API 요청 한도를 같은 것으로 생각하면 안 된다.

- **무료 범위:** 일부 모델은 무료 입력·출력 사용량을 제공한다. 모든 모델과 기능이 무료인 것은 아니다. 선택한 모델의 `Free Tier` 항목을 확인한다. [모델별 가격표](https://ai.google.dev/gemini-api/docs/pricing)
- **정확한 횟수:** 모든 계정에 공통인 “하루 몇 회” 숫자는 없다. 모델·프로젝트·요금 단계에 따라 달라진다. AI Studio에서 해당 프로젝트를 선택하고 사용량과 활성 한도를 확인한다. 이 문서에서는 개인 계정의 실제 한도를 조회하지 않았다.

| 확인할 항목 | 쉬운 뜻 |
| --- | --- |
| RPM | 1분 동안 보낼 수 있는 요청 횟수 |
| TPM | 1분 동안 보낼 수 있는 입력 글의 분량. 토큰이라는 단위로 계산 |
| RPD | 하루 동안 보낼 수 있는 요청 횟수 |

한 항목만 초과해도 제한될 수 있다. 한도는 **API 키별이 아닌 프로젝트별**이며, 일일 요청 한도는 미국 태평양 시간 자정에 초기화된다. 여러 키를 만들어도 같은 프로젝트의 사용량은 합산된다. [사용량 제한과 현재 한도 확인](https://ai.google.dev/gemini-api/docs/rate-limits)

**우리 코드에 적용:** `gui_windows.go`는 6시간 간격으로 `cycle()`을 호출한다. `pipeline.go`에서는 검색어 생성과 논문 요약에 각각 AI 요청을 보낸다. 24시간 기준 약 4회 실행하고 매번 요약할 논문이 있다면 생성 요청은 약 8회다. 모델 목록 조회·재시도·수동 실행은 별도이며, 논문이 없으면 요약 요청은 생략한다. 따라서 “6시간마다 실행하니 하루 4번만 요청한다”로 계산하면 안 된다.

## AI에게 한 질문

- **스토어 등록을 하면 Google 캘린더 로그인도 해결되나?** 별도다. 스토어 등록은 앱 배포 절차이고, 캘린더 접근은 Google Cloud에서 앱 식별 정보와 권한 동의를 준비하는 절차다. [Google 로그인 앱 설정](https://developers.google.com/identity/protocols/oauth2/native-app)
- **무료 한도를 넘으면 자동으로 결제되나?** 무료 단계에서는 보통 한도 오류로 요청이 막힌다. 결제 계정을 연결해 유료 단계로 바꾸면 해당 요금이 적용되므로 프로젝트의 결제 상태를 먼저 확인한다. [결제 안내](https://ai.google.dev/gemini-api/docs/billing)

## 막힌 곳과 해결

- **무료 AI에 넣어도 되는 자료:** 무료 서비스의 입력·응답은 제품 개선에 사용되고 사람이 검토할 수 있다. 개인정보, 비밀번호, 비공개 회사 자료는 보내지 않는다. 지역과 결제 상태에 따른 예외는 약관에서 확인한다. [데이터 이용 약관](https://ai.google.dev/gemini-api/terms)
- **요청 제한 오류:** `429`가 나오면 즉시 반복 요청하지 않고 기다린다. 분당 한도인지 일일 한도인지 확인하고, 코드의 재시도 횟수와 간격도 제한한다.
- **API 키 노출:** 코드나 GitHub에 키를 적지 않는다. 지금 자동 업데이트 프로그램도 키를 입력받아 사용하며 설정 파일에는 저장하지 않는다.
- **Windows 코드를 모바일 스토어에 바로 등록할 수 있나:** 현재 두 소스의 화면 코드는 Windows용이다. Android·iPhone용 화면과 빌드 작업을 별도로 해야 한다. 스토어 계정 생성만으로 변환되지 않는다.
