# 네이티브 버전 검증

2026-10-31 · Windows amd64 · Go 1.27.3

## 통과

- CGO 없이 Win32 Walk 앱 빌드. Common Controls v6와 DPI manifest를 실행 파일에 내장
- `go test ./... -count=1` 및 `go vet ./...`
- 제공자 HTTP 모사: Google 페이지 처리와 반복 일정 쿼리, Microsoft 페이지 처리와 종일 원래 날짜 및 UTC 시각
- callback의 잘못된 Host, 경로, state와 재사용 거부 및 사용자 동의 취소 처리
- 네이티브 앱 설정 파일 저장 및 다시 읽기
- Google Desktop JSON 가져오기 파서와 Web app 및 서비스 계정 거부, 잘못된 JSON 및 누락된 필드와 파일 크기 제한
- Microsoft GUID 검사와 제공자별 3단계 안내 콘텐츠, 데모에서 실제 계정 모드로 전환
- 42일 조회 범위, 종일 종료일 제외, 자정 종료 경계, 검색과 캘린더 숨김
- 임시 임의 자격 증명으로 9000자 이상 토큰의 Windows 저장·읽기·교체·삭제
- 실제 독립 네이티브 창 실행. Win32 버튼, 표, 입력창과 체크박스 확인
- 일반 모드 최초 실행에서 연동 가이드 자동 열림 확인. Google 계정 연결 버튼에서도 해당 가이드가 표시됨
- 최종 가이드 화면의 등록 안내, JSON 가져오기, URI 복사, 입력값 확인, 저장 후 로그인 컨트롤 배치 확인
- 실제 UI에서 날짜 선택 → 두 일정 표시, 표 선택 → 상세 표시, 검색 → 한 일정 표시, 캘린더 체크박스 → 해당 일정 숨김 확인
- DOCX 전체 페이지를 Word PDF 및 PNG로 렌더링해 육안 확인

## 검증 범위의 제한

- 네이티브 자동 조작 도구가 소유된 모달 창의 포커스 및 요소 인덱스를 제대로 처리하지 못해, 가이드 내부 버튼과 파일 선택부터 실제 로그인까지의 전체 UI 자동 검증은 완료하지 못했습니다. JSON 파서와 설정 및 모드 전환은 단위 테스트로 확인했습니다.
- 실계정 Google 및 Microsoft OAuth 동의와 실제 제공자 API 호출은 사용자 앱 ID 및 로그인이 필요합니다.
- CGO 툴체인이 없어 `go test -race`는 수행하지 못했습니다.
- Windows 외 운영체제는 구현 대상이 아닙니다.

실제 연결 후 두 제공자의 원본 일정과 조회 날짜, 종일 일정, 반복 일정을 비교하고 재시작 후 연결이 유지되는지 확인하세요.
