# 0005. 팀 AI 키를 서버에 두고 팀원이 같이 쓰기

- 날짜: 2026-11-17
- 상태: 채택 (0002를 고쳐요: 사용자 키 방식도 그대로 둬요)
- 정한 사람: B

## 배경

0002는 사용자가 자기 AI 키를 폰에 넣는 방식이에요. 개발 중에는 팀원마다 같은 키를 폰마다 넣어야 하고, 해시태그 분류처럼 작은 AI 기능을 붙일 때마다 "키를 넣어 주세요" 화면이 필요했어요.

## 결정

- 팀 Claude 키를 Supabase secret `ANTHROPIC_API_KEY`에 두고, Edge Function `ai`가 대신 불러요(`supabase/functions/ai`).
- 로그인한 팀원(`my_team_role()`)만 쓸 수 있어요. 사람마다 하루 `AI_DAILY_LIMIT`번(기본 100)까지예요.
- 사용량은 `ai_usage`에 횟수와 토큰 수만 남겨요. 요청 원문과 답은 저장하지 않아요.
- 앱에서는 `apps/mobile/lib/team-ai.ts`의 `teamAi.complete(...)`로 불러요. 요청 모양은 `@noteapp/ai-client`와 같아요.
- 모델·설정은 서버가 정해요(`claude-opus-5-5`, effort medium, 거절되면 서버가 다른 모델로 다시 돌림).

## 다른 선택지

- 키를 앱 빌드에 넣기: 앱을 풀면 키가 보여요. 안 해요.
- 팀원마다 자기 키(0002 그대로): 기능을 붙일 때마다 키 입력이 필요해요. 일반 사용자용으로는 그대로 둬요.

## 결과

- 팀원은 키 없이 로그인만 하면 AI 기능을 써요.
- AI 비용은 팀 키로 나가요. 하루 한도로 막고, `ai_usage`로 누가 얼마나 썼는지 봐요.
- 팀원이 아닌 사용자에게 AI를 열 때(출시 등) 한도·과금을 다시 정해요.
