# 0004. 레포는 공개

- 날짜: 2026-10-26
- 상태: 채택

## 배경

학습과 포트폴리오가 목적이에요. 무료 플랜에서는 공개 레포여야 브랜치 보호와 CODEOWNERS 리뷰 강제를 쓸 수 있어요.

## 결정

레포를 공개로 운영해요.

## 결과

- 키·토큰·`.env`는 절대 커밋하지 않아요. Secret scanning과 Push protection을 켜요.
- `docs/product/`에 개인정보(실명이 보이는 스크린샷, 연락처 등)가 담긴 자료를 올리지 않아요.
- 라이선스는 팀에서 정해요. 참고 앱 DayOtter(AGPLv3) 코드는 가져오지 않아요.
