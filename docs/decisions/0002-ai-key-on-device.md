# 0002. 사용자 AI 키는 기기에만 저장

- 날짜: 2026-10-26
- 상태: 채택

## 배경

AI 초안·카드 추출에 Claude·OpenAI·Gemini를 써요. 키를 서버에 두면 서버 비용과 보안 책임이 생겨요. 참고한 AI 캘린더 PRD는 키를 서버에 두는 방식이라, 이 부분은 다르게 정했어요.

## 결정

- 사용자가 자기 API 키를 설정에서 입력하고, 기기의 보안 저장소(`expo-secure-store`)에만 저장해요. 코드는 `apps/mobile/lib/secrets.ts` 한 곳이에요.
- AI 호출은 앱에서 AI 회사로 직접 해요 (`@noteapp/ai-client`).
- 키와 요청 원문은 서버·DB·로그에 남기지 않아요.

## 결과

- 서버에 AI 비용이 들지 않고, 키 유출 책임이 줄어요.
- 사용자마다 키가 있어야 해요. 데모 때는 팀원 키를 각자 폰에 넣어요.
- 서버에서 AI를 써야 하는 기능(예약 실행 등)이 생기면 이 결정을 다시 봐요.
