# 기획 자료

이 앱은 팀원 세 명의 기획을 합친 거예요.

| 자료                                             | 이 앱에 들어온 것                                                                |
| ------------------------------------------------ | -------------------------------------------------------------------------------- |
| 오르카짱 GitHub 공용 레포 설계                   | 모노레포, 기능별 담당, 계약 먼저, 브랜치·PR 규칙                                 |
| noteApp(가안) 기획 공유                          | 세션 템플릿, AI 초안, 단계별 서버 도입, AI 규칙 파일, 학습일지, 파일 저장소 계획 |
| 다모아버림 설계                                  | 막 쓰기 → 카드 추출, 제안 후 확인, 원문·출처 보존, 추출 테스트 세트              |
| AI 통합 캘린더 PRD v1.0, 다중 Calendar Sync 조사 | 캘린더 연결, 시간 후보 3개와 이유, 수행 확인(완료·부분·못 함·모름)               |

참고 앱: OneCal, DayOtter(구조만 참고, AGPLv3라 코드는 가져오지 않음), Motion, Reclaim.ai

원본 PDF·목업을 여기에 둘 때는 실명·연락처가 보이는 부분을 가린 뒤 올려요. 레포가 공개이기 때문이에요.
